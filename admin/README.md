# /admin - Herramientas de Administración

Contiene herramientas para administración del sistema.

## Archivos

- **admin-backup.php** - Creación de respaldos
- **admin-settings.php** - Configuración avanzada
- **backup_handler.php** - Manejador de respaldos
- **clean_entries.php** - Limpieza de registros ⚠️ (requiere confirmación)
- **data_quality.php** - Análisis de calidad de datos
- **phpinfo.php** - Información del servidor PHP
- **extension-tokens.php** - Gestión de tokens de extensión

## Acceso

Estos archivos requieren login y permisos de administrador.

## Advertencia

Algunas herramientas como `clean_entries.php` son peligrosas. Úsalas solo si sabes lo que haces.
