# /tools - Herramientas de Mantenimiento y Análisis

Contiene herramientas para análisis, importación y procesamiento de datos.

## Archivos

- **analyze_data_summary.php** - Análisis resumido de datos
- **analyze_excel.php** - Análisis de archivos Excel
- **auto_import.php** - Importación automática de datos
- **chrome-addon-help.php** - Ayuda para la extensión Chrome
- **ocr_processor.php** - Procesamiento de OCR

## Acceso

Estas herramientas requieren login y generalmente permisos de administrador.
