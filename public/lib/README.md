# /lib - Helpers y Librerías Comunes

Contiene archivos de apoyo, clases y funciones reutilizables:

- **JWTHelper.php** - Gestión de tokens JWT
- **SecurityHeaders.php** - Headers de seguridad HTTP
- **LogAnalytics.php** - Análisis de logs
- **LogConfig.php** - Configuración del sistema de logging
- **improvements_functions.php** - Funciones de mejora y utilidades

Estos archivos se cargan desde el código principal cuando se necesitan.
