# /tools - Herramientas de Mantenimiento y Análisis

Contiene herramientas utilitarias para análisis, importación, limpieza y configuración de datos.

## Archivos - Análisis

- **data_quality.php** - Control de calidad de datos

## Archivos - Importación

- **import.php** - Importación de fichajes
- **import-calendar-beta.php** - Importación de calendario (beta)
- **auto_import.php** - Importación automática de datos
- **chrome-addon-help.php** - Ayuda para la extensión Chrome
- **firefox-addon-help.php** - Ayuda para la extensión Firefox

## Archivos - Base de Datos

- **db_add_expected_daily_hours.php** - Agregar horas esperadas diarias
- **db_set_expected_daily_hours.php** - Establecer horas esperadas diarias
- **db_read_2026.php** - Leer datos de 2026

## Archivos - Configuración y Limpieza

- **fix_config_2026.php** - Reparar configuración de 2026
- **fix_config_2026_full.php** - Reparar configuración completa de 2026
- **clean_entries.php** - Limpiar entradas de datos
- **dashboard_merged.php** - Dashboard alternativo (merged)

## Notas

- Estas herramientas requieren login de usuario
- Muchas requieren permisos de administrador
- Úsalas solo si sabes qué estás haciendo
- Se recomienda hacer backup antes de usar tools de limpieza/reparación
